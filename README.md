# 🐍 Snake Game
A modern and responsive **Snake Game** built using **HTML, CSS, and JavaScript**. Control the snake, eat food to increase your score, and avoid collisions with walls or yourself. This project demonstrates core JavaScript concepts including DOM manipulation, event handling, game loops, collision detection, and responsive UI design.

Live Demo: https://snakegamebyaarkeshsharma.netlify.app/

## 📖 Overview
This project recreates the classic Snake Game with a clean user interface and smooth gameplay. It is designed as a frontend project to strengthen JavaScript fundamentals while providing an engaging gaming experience.

## ✨ Features
* 🎮 Smooth and responsive gameplay
* 🐍 Dynamic snake movement
* 🍎 Random food generation
* 📈 Live score tracking
* 💀 Collision detection
* 🔄 Restart game functionality
* ⌨️ Keyboard controls
* 📱 Responsive design for different screen sizes

## 🎮 How to Play

* Use the **Arrow Keys** (⬆️⬇️⬅️➡️) to move the snake.
* Eat the food to increase your score.
* Avoid hitting the walls.
* Avoid colliding with your own body.
* Try to achieve the highest score possible!
